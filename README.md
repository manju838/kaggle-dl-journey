# Kaggle-DL-Journey


Structure in this repository:
```bash
kaggle-dl-journey/
├── README.md                # index of all competitions + key learnings
├── 01-competition-1/
│   ├── notebook.ipynb
│   ├── README.md            # what you tried, what worked, score, lessons
├── 02-competition-2/
├── 03-competition-3/
├── ...
├── notes/
│   ├── architectures/       # one .md per architecture (CNN.md, RNN.md, etc.)
│   └── glossary.md
```

Per-competition README template:

- Problem type & data shape
- Baseline approach + score
- What you changed, and why
- Best score + what mattered most
- 3 things you'd do differently next time
